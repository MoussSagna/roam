# ROAM — Product Context

## Vision

ROAM helps people decide what to do by understanding their current context and turning it into a realistic outing.

The central product promise is:

> “Me proposer une sortie adaptée à ma situation.”

ROAM is not primarily a directory of places.

## Core hypothesis

If ROAM knows:
- mood;
- available time;
- budget;
- company;
- location;
- preferences;

then it can propose a relevant outing that the user can realistically complete.

## Core loop

```text
User context
    ↓
Personalized recommendations
    ↓
Choose an experience
    ↓
ROAM builds an itinerary
    ↓
User completes the outing
    ↓
User gives feedback
    ↓
Future recommendations improve
```

## MVP success criterion

A user must be able to:

1. create a profile;
2. describe what they want to do now;
3. receive several relevant recommendations;
4. understand why they were recommended;
5. select an experience;
6. obtain a coherent itinerary;
7. view it on a map;
8. complete the outing;
9. give feedback.

## Explicitly out of MVP

- conversational AI;
- public profiles;
- following/friends/feed;
- advanced social comments;
- reservations;
- payments;
- ticketing;
- subscriptions;
- advertising;
- marketplace;
- sponsored offers;
- complex ML recommendation;
- advanced gamification.

## Product positioning

The key distinction is:

> “ROAM does not just help me find places. ROAM helps me decide what to experience.”
